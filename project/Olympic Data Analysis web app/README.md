# Olympic Data Analysis Web App — Project Copy

This directory contains a copy of the Streamlit Olympic analysis application within the broader Data Science portfolio.

For the maintained project overview, setup instructions, dashboard capabilities, methodology, and limitations, use the standalone repository documentation:

- [Main GitHub repository](https://github.com/PARAG-TIWARI/olympic-data-analysis-web-app)
- [Main README](https://github.com/PARAG-TIWARI/olympic-data-analysis-web-app#readme)
- [Live Streamlit application](https://olympic-data-analysis-web-app-am3jfyvy4gxsad7yi4xbug.streamlit.app/)

## Local files in this copy

- app.py — Streamlit dashboard.
- helper.py — aggregation and analysis functions.
- preprocessor.py — Summer Games filter, NOC mapping, and medal indicators.
- athlete_events.csv — athlete-event dataset.
- noc_regions.csv — NOC-to-region mapping.

The application explores medal tables, participation trends, country performance, and athlete statistics. It filters the data to Summer Olympic records.

To avoid documentation drift, the standalone repository README is the canonical project documentation. Check it before running or describing this copy.
